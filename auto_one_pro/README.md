# AUTO ONE - Foundation

نسخة تأسيسية لتطبيق معرض السيارات:
- واجهة رئيسية فخمة
- مخزون سيارات قابل للبحث والتصفية
- صفحة تفاصيل السيارة ومعرض صور
- حالة السيارة: متاحة / محجوزة / مباعة
- نموذج حجز مرتبط بالسيارة
- لوحة إدارة أولية للإحصائيات وطلبات الحجز

## التشغيل
```bash
flutter pub get
flutter run -d chrome
```

هذه النسخة تستخدم Repository محليًا للتجربة. المرحلة التالية هي استبداله بقاعدة بيانات حقيقية ولوحة إدارة فعلية ورفع صور.
